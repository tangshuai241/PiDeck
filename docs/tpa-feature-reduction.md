## 长期判断

功能多可以增加选择，也会增加依赖、启动资源、测试、配置和兼容成本。长期保留的判据是能否提供独有价值，而不是当前是否每天使用。

- 对话、历史、材料、成果、模型、权限、MCP、备份和恢复属于核心能力。
- Pi 与 DSH 有不同运行时。用户计划长期使用两者，本轮保留 DSH。
- 生图、生视频、语音、飞书、桌宠、CUA、Git、终端和浏览器属于按需能力。保留能力不意味着必须常驻运行；后续可按实际测量优化启动和资源占用。
- 用户不计划使用 ACP，因此删除它的配置和执行链。系统终端中的外部 CLI 仍可独立使用。
- Web 工作台与飞书并不完全重复，但当前只保留飞书远程消息入口，停止维护 Web 工作台。
- 上游运营公告、上游遥测、在线推荐入口不属于个人助理的核心能力，可删除。
- 不在本轮增加插件化重构，也不把「隐藏入口」视为已经停掉后台服务。

## 四项删除路线与影响

### ACP 外部 CLI 后端

作用：在工作台配置和启动 Claude Code、Gemini、Kimi、OpenCode 等外部 Agent CLI。

删除理由：用户计划使用 Pi 与 DSH，不需要第三套通用 Agent 接入与生命周期管理。

已移除主进程 acp 域、ACP IPC、preload API、配置页、工具探测、输入框工具控制、引导页与新建菜单入口。会话激活在创建进程前拒绝旧 ACP 标记；创建和更新 IPC 拒绝 ACP 选择。

影响：应用不再启动外部 CLI。既有 CLI 安装与外部终端使用不受影响。旧会话记录和工具配置不删除；旧 ACP 默认偏好回落 Pi。失败发送不会自动删除旧 ACP 草稿。

### 局域网 Web 工作台

作用：通过手机或其他设备的浏览器访问本机完整工作台。

删除理由：当前不维护浏览器远程工作台，保留飞书消息入口。

已移除主进程 web 域、监听和远程访问服务、Web 设置与 IPC、Web 页面和 Vite 入口、专属测试。删除仅供 Web 使用的 AI SDK 直接依赖。

影响：浏览器不能再访问本机远程工作台。桌面窗口、内置浏览器、飞书、会话命令与 Git 继续使用自己的本地链路。旧 Web 配置保留读取兼容，启用字段强制关闭。

### 在线推荐与商店

作用：从外部市场发现、搜索和安装提示词、技能、扩展。

删除理由：停止维护在线发现与推荐入口，保留已经安装的资源和主动管理能力。

已移除在线搜索与市场 IPC、SkillHub、扩展市场和推荐组件，以及专属抓取、安装辅助模块。提示词商店收敛为社区词库入口；本地技能与扩展列表继续保留。

影响：应用不再提供这些在线发现页面。社区词库仍可分类、搜索、预览与导入。个人提示词、技能、扩展和项目资源不删除；sql.js 仍供词库和 Kimi Work 历史使用。

### 上游公告与遥测

作用：公告展示原项目的运营消息；遥测上报功能开关与使用计数。

删除理由：个人 fork 不需要原项目的运营通知和统计服务。

已移除公告与遥测服务、启动与退出装配、公告 IPC、同步与通知 hooks、公告中心、设置入口、公告资源与生成脚本。CI 和发布检查不再调用公告生成命令。

影响：不再获取公告或上报遥测。飞书通知、桌面任务提醒、更新提示、错误日志与进程监控继续保留。旧遥测开关不能重新启用服务。
