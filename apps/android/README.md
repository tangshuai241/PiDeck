## 0.1.3 消息操作、模型选择与滚动

- 用户消息恢复分支、书签、复制三枚图标，图标为 14 号；助手消息提供书签和复制。分支复用电脑会话服务，恢复所选消息到新会话草稿，不自动重发。书签只写手机加密缓存，不修改 Pi 会话。超长消息的复制入口先打开完整正文。
- 手机保存模型偏好，发送或创建会话时提交模型身份。电脑沿用同一会话，并显示实际模型。不可用模型、过期运行时、运行中的跨模型切换均拒绝发送，不静默回退。列模型期间运行时变化也会重新校验。
- GFM 解析禁用单波浪删除线，与电脑配置一致。原文 `18~26℃` 保留为温度范围；双波浪删除线仍可使用。
- 正文基线为 13 号字、20 行高；过程说明为 12 号字、17 行高；辅助说明为 11 号字、16 行高。过程默认展开，单条详情默认收起，用户仍可手动折叠。
- 列表靠近底部时跟随输出。主动上翻后暂停跟随，新输出显示提示；点击“回到最新消息”恢复跟随。展开详情只保护本次布局，不永久关闭跟随。

- 最终回复与完整正文页支持 GFM 表格、标题、强调、列表、引用、链接与代码块。宽表格和代码块可以横向滚动。
- 解析使用桌面 Streamdown 所用的 `unified`、`remark-parse`、`remark-gfm`，增加原生视图适配；没有引入另一套 Markdown 引擎或 WebView。新增直接依赖的原因是 Android 不能呈现桌面 DOM 组件。
- HTML 按文字显示，图片仅显示说明文字；链接只允许网页和邮件协议。超过预览预算或结构过深的内容保留为可选择文本。

## 0.1.1 对话体验修订

- 0.1.1 的正文基线为 15 号字、23 行高；0.1.2 改为 14 号字、21 行高，聊天页左右留白为 18。过程说明采用 13 号字、20 行高。系统字体缩放保持启用。
- 每轮对话显示一个执行过程入口，分别统计工具、思考和阶段回复。最终回答保持可见。历史窗口缺少本轮开头时，入口标注“部分执行过程”。
- 过程默认折叠。用户展开后，内容更新和列表回收不清除展开选择。工具失败数量保留在汇总中。
- 命令名和工具详情采用等宽字体。没有可靠耗时的条目不显示耗时。
- 页面进入采用 180 ms 过渡。按钮提供按下反馈，过程展开采用布局过渡。减少动态效果设置会关闭这些过渡。
- Android 键盘弹出时抬起输入区，收起时恢复完整高度；真机连续打开和收起后没有残留空白。
- 桌面远程投影在截断前分离正文和思考，完整内容读取采用同一规则。手机兼容旧版电脑的混合字段和分页内容。手机保留原始消息、游标及版本摘要，不改写会话。

真机回归步骤保留如下，后续修改动画与输入布局时重复执行：

3. 打开输入键盘，确认输入框与发送按钮可见；收起键盘，确认列表与输入区恢复完整高度。测试期间不发送内容。
4. 将系统字号改为 130%，重复打开会话；关闭系统过渡动画后重复展开与滚动。测试后恢复原设置。
5. 在深浅色间切换，检查过程说明和命令文字；切后台后回前台，确认原有配对仍可读取会话。

## 当前连接

手机与电脑分别通过 WSS 连接自建服务器。电脑沿用现有 Pi 会话和 stdio JSON-RPC；中继只转发密文。手机显示桌面已公开的思考内容和工具事件，不生成虚构进度。

- 配对需电脑生成邀请，并在电脑确认设备。邀请十分钟有效。
- 正文、思考和工具状态采用事件触发的增量更新；前台恢复按游标补传，游标失效则回读快照。
- 操作身份先保存，再发送。回执丢失时查询原指令，不自动再次执行。
- 手机草稿与缓存加密保存。切后台暂停连接，回前台恢复；没有后台推送保证。
- 项目与定时任务复用桌面目录和任务存储，不另建代理或任务系统。

## 开发与构建

依赖单独安装在本目录，不修改桌面根目录的依赖。版本由本目录的 lockfile 固定。

```powershell
npm ci
npx expo prebuild --platform android --no-install
node scripts/collectNotices.cjs
npx tsc --noEmit
```

Android SDK、JDK 17 和 Gradle 缓存放在工作区 `cache/TPA-android-toolchain`，没有修改系统 Java、SDK 或全局 Gradle 配置。

Windows 在本目录执行以下命令。先设置本机的 `JAVA_HOME`、`ANDROID_HOME`、`GRADLE_USER_HOME`；个人签名另需设置 `TPA_ANDROID_KEYSTORE` 和 `TPA_ANDROID_KEY_PASSWORD_FILE`。密码文件和密钥不放进仓库或交付包。

```powershell
android\gradlew.bat -p android assembleRelease -PreactNativeArchitectures=arm64-v8a --no-daemon --max-workers=1 "-Dorg.gradle.jvmargs=-Xmx1024m -XX:MaxMetaspaceSize=768m" -Pkotlin.compiler.execution.strategy=in-process -I scripts/mirrors.init.gradle
```

`mirrors.init.gradle` 仅对这次构建使用项目镜像、单并发 C++ 编译和单工作线程的 Metro 打包，避免占满本机内存。未设置个人签名变量时，Expo 模板会用调试签名；此时不得把产物标作个人签名包。

## 首版边界

- 首版接入 Pi 会话。DSH、生图运行时和 GitHub 工作树没有接入。
- 聊天正文已接入常用 Markdown 与 GFM 表格。代码语法高亮、数学公式、图表和附件发送仍待实现；完整内容跨分页的表格只能按各页已有文本解析。
- 每次快照最多 80 个可见条目，实时正文、思考、工具详情各保留尾部 12,000 字符，历史视图最多 600 条。超长条目可打开完整内容并按每段 10,000 字符分页读取；版本变化时要求重新读取，单条上限 6,400 万字符。Pi 自身截断且未输出的内容不会补造。
- 文稿归档成果下载上限 10 MB，不开放任意电脑文件路径。
- 多工作区和邀请成员保留参考布局，点击说明个人版本边界；没有伪造账户服务。
- 持续帧率、断网切换和长时间使用尚未验收；本轮短时真机检查不能替代这些测试。

相关实现与证据见 `../../docs/tpa-android-remote-v1.md`。
